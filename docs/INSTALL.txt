LiveCopilot — Installation

Requires macOS 14+, Apple Silicon or Intel. Apple Speech additionally requires
macOS 26+, supported hardware and languages; Laya requires Apple Silicon.
No separately installed developer tools, Python, or Ollama are needed.

1. Quit the old version, drag LiveCopilot.app into Applications (or ~/Applications),
   and launch from that consistent location. Eject the DMG. Do not keep renamed
   same-identity app backups beside the live application.
2. Official distribution builds use Developer ID Application: Bokai Zhang
   (666N9BJMD7), Apple notarization, and tickets stapled to both app and DMG.
   A normal installation does not require Open Anyway; standard first-download
   confirmation can still appear. Verify against the release's SHA256SUMS.txt.
3. Follow the six-step first-run guide or reopen it from Settings > General.
   Select Zipformer for local Chinese/English speech, or choose Paraformer,
   supported Apple Speech, or OpenAI Live. Download/prepare required resources.
   Choose local BGE-M3 or OpenAI Embeddings for knowledge. Local speech can use
   Laya for automatic response detection; GPT-Live-1 delegates independently.
   Model downloads verify pinned SHA-256 and use fallback sources when needed.
4. Choose an analysis service (OpenAI, DeepSeek, Qwen, GLM, Kimi, or compatible API)
   and save your own key. Keys stay in macOS Keychain; startup reads silently.
   Explicitly authorize an old saved key when requested. Enter a system password
   only in macOS dialogs, never in a chat or document.
5. Grant required audio permissions when listening, or type without capture.
   Local speech/embeddings keep audio and indexing text on-device. Cloud options
   send corresponding content. Answer generation sends the question, relevant
   conversation, and retrieved passages to the selected analysis service.
6. Option + H is the default overlay shortcut and can be customized. Edge hiding,
   pinning, and automatic height are configurable. Refresh clears active context
   and draft; active listening starts fresh. Knowledge/saved history remain.
   About links to the author, repository, and bilingual product guide.
7. Use Check for Updates in the application's update controls. Saved automatic
   check preferences remain; download/install are user-controlled. Releases 2.0
   and earlier need one manual upgrade because they lack the updater.

The package contains no user keys, documents, history, or knowledge database.
Upgrades retain local data. Migrating from ad-hoc signing may require renewed
recording/Keychain permission. Official updates retain team and bundle identity;
macOS still controls permission decisions. Local models have no API usage fee
but use local resources. Cloud usage is billed to your own account.
Capture exclusion is optional and depends on macOS/capture software; Settings
and History remain capturable. Verify sharing from another participant's view.
