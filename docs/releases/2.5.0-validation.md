# LiveCopilot 2.5.0 release validation

Validated on 2026-10-18 (Asia/Shanghai) using a fresh, non-shared Git clone of source commit `b72996db46b23c61a1582cc1de465c0c6f1ab873`.

## Small installer and immutable model

The clean Release build contains universal arm64/x86_64 app and native binaries. No Laya weights are bundled: `Contents/Resources/LayaRuntime` occupies about 64 KiB and contains only runtime scripts, pins and acceptance metadata. Build and packaging gates reject a bundled `ResponseModel` directory. Onboarding and Services explicitly download the model.

## Regression and native runtime checks

- Clean full XCTest run: 234 tests, 22 conditional skips, zero failures.
- Five opt-in real-Laya integration cases: five passed, zero skips/failures. Covers actual downloaded weights, contextual requests, queueing, stable ASR revisions, withdrawn/incomplete speech and English captions. Answer generation in these tests uses a mock provider; no paid analysis request is involved.
- Standalone core: 72 checks passed. Trigger state machine: 31 checks passed.
- Shipping Python checks: four model distribution tests, nine worker tests and fifteen download tests passed.
- Signed native embedding runtime: real install/load/self-check passed; diagnostic pasteboard roundtrip passed; missing runtime and memory failures produced distinct advice; same-size corruption failed validation and reinstall recovered; cancellation preserved the installed model.
- Existing history tests cover legacy data, multi-turn retention, title generation, export/search/deletion and long-session native scrolling. Earlier interactive acceptance is recorded in [History acceptance](../HISTORY_SESSION_ACCEPTANCE.md).

Conditional live API/hardware tests were not represented as passed. This release does not establish the original cause on the two reported users' unknown hardware. Production histories, settings, credentials and model installations were not reset by testing.
