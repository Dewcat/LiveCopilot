# LiveCopilot 2.5.0

## Complete conversation history

History now presents searchable sessions and a readable timeline of voice transcripts, manual questions, AI answers and retained citations. Date groups, message counts, duration, Markdown/TXT export, per-message copy and deletion confirmation make long conversations easier to review. Existing transcript-only archives remain readable without inventing missing answers.

Sessions can receive an automatic title from the configured analysis API after listening ends. Naming uses question/answer context to correct obvious speech homophones in titles without rewriting transcripts. Rename and regenerate actions are available in the session context menu.

## Local model reliability

Downloads now include real load checks, actionable recovery advice and copyable diagnostics without API keys or document text. Embedding initialization uses a smaller initial context and can fall back from GPU to CPU. Failed knowledge documents can be reindexed after the model passes its check.

Zipformer is the recommended local Chinese/English speech engine; Paraformer remains available. Terminology enhancement is opt-in. The accepted fine-tuned Laya response-intent checkpoint downloads from an immutable ModelScope revision during onboarding or service setup. The small app installer contains no Laya weights; file checksums are enforced during download and load, and old model installations require an explicit update. Its context budget remains 1,024 tokens; it decides when a response is needed, while the analysis API generates the answer. The local Laya runtime remains Apple-silicon-only; universal app packaging does not imply Intel support for that runtime.

## A clearer native interface

Model download, self-check and removal controls share one row, with diagnostics below. Answer style follows API credentials. Transcript and answer font controls sit side by side. Background choices apply only to the floating window; settings keep a white surface. Screen-capture exclusion defaults off, and existing explicit choices are preserved. Retrieval defaults to five evidence snippets. Floating-window guidance is dismissible.

Repository documentation is now English. The app and website retain their language options. Existing settings, credentials, downloaded models and history are preserved during updates.
